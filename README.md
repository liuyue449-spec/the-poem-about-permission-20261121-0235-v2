A short original poem about agency: the power to ask and to be given.
A spare key lies under a mat for years, kept not against thieves but
for the day it might be asked for. The speaker rehearses on the step,
too polite to knock — until the day they finally ask, and learn the
key was theirs since the day they needed it. Permission, the poem
says, can wait a long time; asking is what makes it real.

`main.py` writes the poem to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). It runs offline, stdlib only,
Python 3.13, and the poem is inside the 1–280 character limit.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
